# Phys-Notes

[phys-notes.netlify.com](https://phys-notes.netlify.app/)

A series of notes by Brett Deaton to young physicists. Inspired by things
spotted in nature that prompt questions or analysis.

## Tools
- Vite + React — frontend framework
- Sanity — headless CMS and content editor
- Netlify — static hosting and deploys

## Deployment
The frontend is deployed at `phys-notes.netlify.app`.
Content is authored and published via Sanity Studio at `phys-notes.sanity.studio`.
